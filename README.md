# Welcome to Infinite TIC-TAC-TOE ^-^

Clone this repository using the following command:

```sh
git clone https://github.com/ppp16bit/infinite-tictactoe
```

## Prerequisites

- **Haskell Compiler:** You need [GHC (Glasgow Haskell Compiler)](https://www.haskell.org/ghc/) installed on your system.  
- **Git:** To clone the repository.


## Compilation

Navigate to the repository's directory and compile the code using GHC:

```sh
cd repository-name
ghc Tictactoe.hs -o Tictactoe
```


After compilation, run the executable:

```sh
./Tictactoe
```

**On Windows (Command Prompt or PowerShell):**
```cmd
Tictactoe.exe
```

## Rules

- **Infinite Gameplay:** The game never ends rounds continue indefinitely.
- **Scoring:** Winning a round gives the winner 1 point.
